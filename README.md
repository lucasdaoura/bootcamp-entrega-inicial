Sistema simples de controle de medicamentos para resolver o problema de esquecimento de doses.
# 💊 MedControl - Apoio ao Idoso

## 🎯 O Problema
Muitos idosos possuem dificuldades em gerenciar horários de múltiplos medicamentos, o que pode levar a erros graves de dosagem ou esquecimento.

## 🚀 A Solução
O MedControl é uma ferramenta CLI (Linha de Comando) simples que permite cadastrar e visualizar agendamentos de remédios, garantindo que o cuidador ou o idoso tenham um registro claro do dia.

## 🛠️ Tecnologias e Boas Práticas
- **Linguagem:** Python 3.10
- **Versionamento Semântico:** v1.0.0
- **Testes:** Pytest (Garantia de funcionamento das funções)
- **Qualidade:** Ruff (Análise estática de código)
- **CI/CD:** GitHub Actions (Automação de testes em cada push)

## 📦 Como usar
1. Clone o repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o app: `python src/app.py`
4. Execute os testes: `pytest`
